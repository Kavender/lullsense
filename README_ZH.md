# LullSense（知眠）

> 面向每个家庭的开源婴幼儿睡眠智能。

![License](https://img.shields.io/badge/license-Apache--2.0-blue)
![Scope](https://img.shields.io/badge/适用月龄-4–36%20个月-brightgreen)
![Safety](https://img.shields.io/badge/安全优先-绝不做诊断-orange)
![Status](https://img.shields.io/badge/状态-未发布（私有）-lightgrey)

LullSense 是一个 Agent Skill（智能体技能），通过**基于证据的对话**帮助家长理解婴幼儿睡眠，并在有睡眠数据时提供**可选的纵向模式检测**。它**仅凭对话**就能给出真正有用的帮助——不需要付费 App、记录工具或订阅。

> **数据能让答案更好；但数据从来不是使用它的门票。**

它是教育性、支持性的工具——**不是医疗器械**。它绝不做诊断，永远先做安全排查，并且对「哪些是有据可依的证据、哪些是可调整的经验法则」保持诚实。

---

## 为什么做这个项目

优质的睡眠帮助往往很贵、被订阅制挡在门外，或者在凌晨 3 点隔着一整个时区。权威指南（AAP 安全睡眠、AASM 睡眠时长共识、发育相关文献）本是公开的，却零散、难以在凌晨 3 点套用到**你自己**孩子身上。本技能把这些公开证据提炼为一份平和、个体化的咨询，让任何有能力的 AI 智能体都能承载——免费、可检查、且安全。

## 示例

**没有数据，仅凭对话：**

> **家长：** 我家 8 个月的宝宝突然每天早上 5 点就醒，是不是哪里出问题了？
>
> **顾问：** 每天 5 点醒确实让人筋疲力尽——我们一起来理一理。先快速确认一下：她其他方面都好吗——吃奶正常、没有新出现的鼻塞或发烧？……好。这个月龄的早醒很常见，通常有几个常见诱因。跟我说说她大概几点入睡、最近几晚是什么情况，我会带你看两个最可能的解释、以及一个可以先试的小调整——还会明确告诉你要观察什么，好判断是否奏效。

**有近期睡眠记录（「最近睡得怎么样？」）：**

> **家长：** 帮我看看过去两周的情况？
>
> **顾问：** 先说好消息——纵观她的夜觉、小睡、入睡时间、总睡眠量以及作息的稳定程度，大部分都保持得很稳。有一处发生了变化：这一周她的早晨提前了大约 40 分钟。下面说说可能的原因、什么情况会让我改变判断、以及一个可以先试的调整……

本技能呈现的是**带有证据与局限的「信号」和「假设」**——绝不是诊断，也不会一次性把整篇分析砸给你。

## 它能做什么

- **无数据模式（主路径）。** 基于一个带版本、可溯源的知识库，从家长的叙述出发推理。口头描述（「整周都在 5 点醒」）本身就是真实证据。
- **数据增强模式。** 可选地导入一份睡眠记录——手写笔记、通用 CSV/JSON，或 Huckleberry 官方导出——将每个孩子的**基线**与**检测信号**纳入推理。
- **主动回顾。** 由家长发起的「回顾我最近的睡眠」流程，把检测信号转化为一份平和、有优先级的变化摘要——经过封顶、去重，并以**保持稳定**的部分开头——刻意避免「警报疲劳」。
- **约束优先、有计划。** 在给建议**之前**先了解硬性约束（托育小睡、接送时间、上班），提出最小可用的实验，并为跨多天的过渡给出逐日路线图。
- **极简的本地存储。** 只保存孩子档案（出生日期，让月龄永不过时）、家长明确保存的长期约束，以及实验状态——**从不保存原始睡眠记录**。

### 核心原则

| 原则 | 含义 |
|---|---|
| **安全优先** | 在任何作息建议之前先排查红旗信号；一旦出现红旗，就**停止**优化并引导就医——语气温暖，且绝不点名病因。 |
| **绝不诊断** | 只呈现带证据与局限的信号与假设。诊断是临床医生的工作。 |
| **绝不编造** | 每一个有据可依的数字都注明来源；经验法则标注为「产品经验法则——可调整，非临床阈值」；文献未给出阈值处，就如实说明。 |
| **个体化** | 权威文献是**参考，不是操作手册**——同样的表现可能有不同的成因；建议永远针对**这一个**孩子和家庭。 |
| **数据可选** | 仅凭对话即可获得完整价值；从不要求使用记录工具。 |

## 支持范围（首个 alpha）

- **4–36 个月**：行为/作息方面的支持。
- **4 个月以下：** 仅提供**安全睡眠护栏**——安全睡眠要点与红旗排查，不做作息优化。

## 安装与使用

```bash
npx skills add Kavender/lullsense
```

将技能安装到你的智能体中（例如 `~/.claude/skills/lullsense/`）。之后只需用自然语言提出婴幼儿睡眠问题即可。

**可选的分析引擎**（数据增强 + 主动回顾）：

```bash
pip install lullsense       # 提供 lullsense-analyze / lullsense-experiment 命令
```

仅凭对话，本技能就已完整可用——数据从来不是必需的。

> 从源码使用？`git clone https://github.com/Kavender/lullsense.git`

> **状态：** 未发布，且为**私有**——只有在完全建成并测试通过后才会公开发布。

## 它知道什么

一个四层、带版本的证据库——**53 条断言（claims）**、**29 个来源（sources）**，由 schema/安全校验器（`scripts/validate_knowledge.py`）验证。

| 层级 | 内容 | 证据门槛 |
|---|---|---|
| **A — 安全** | 安全睡眠、红旗排查、新生儿护栏 | 仅限指南 / 专业共识 / 系统综述；高证据等级；须有来源（强制） |
| **B — 发育** | 睡眠常态、区间、小睡过渡、发育阶段 | 引用文献（AASM、Spencer、Tham、Galland 等） |
| **C — 行为** | 自主入睡、夜醒、睡眠训练方法 | 参考系统综述；对各种干预方式不带评判地呈现 |
| **D — 实践** | 咨询技巧、约束采集、复评 | 综合公开实践；经验法则明确标注为经验法则 |

呈现方式、语气与咨询主线由一个专门的**人格层（persona）**承载——温暖、不评判、减少内疚，并且「校准」（在同一句话里既安抚「大概率无害」的部分，又点明什么情况会改变判断）。

---

## 安全与诚实的局限

- **仅为教育 / 一般健康用途。** 它不诊断、不治疗、不预防任何病症，也不能替代儿科医生。
- **红旗即停。** 任何安全红旗都会停止睡眠优化，并引导你寻求适当的医疗照护。
- **安全内容有来源支撑。** 只来自权威、经核验的来源；运行时的网络搜索永远不能支撑安全结论。
- **经验法则会被标注。** 作息阈值与严重度分档是可调整的产品经验法则——不是临床标准。
- **一手实践是一个假设。** 咨询人格是一个关于「好实践」的、强而可检验的假设——有待真实用户验证，而非视为已被证明。

## 工作原理

```
skills/lullsense/SKILL.md  ── 精简路由：安全 → 月龄 → 目标 → 约束 → 模式 → 假设 → 最小实验
   │
   ├─ skills/lullsense/references/*.md   13 份按需加载的参考（安全、推理、人格、发育、误区、干预、睡眠训练、信号分类、provider/数据契约…）
   ├─ skills/lullsense/knowledge/*.yaml  带版本的 claims + sources（+ validate_knowledge.py）
   │
   └─ baby_sleep/       可选、厂商中立的分析引擎（纯 Python）
        ├─ contract/    规范化睡眠记录 schema（ApproxTime、溯源）
        ├─ ingest/      手写文本 / 通用 CSV / JSON / Huckleberry 官方导出 适配器
        ├─ analyze/     清醒日切分、约 22 个特征、稳健的每孩基线
        ├─ detect/      10 个基于基线、按月龄门控、非诊断的信号检测器
        ├─ review/      主动回顾摘要（排序 · 去重 · 封顶 · 稳定域 · 新鲜度守卫）
        └─ store/       极简状态：孩子档案 + 已保存约束 + 实验（不存原始记录）
```

一切都可检查、确定性强；推理层厂商中立（不含针对特定 provider 的行为），数据 provider / MCP 集成完全可选。
